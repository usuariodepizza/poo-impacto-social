# ♿ App Rota Acessível (ODS 10)

Protótipo em Python (console) de um mapa colaborativo onde cadeirantes e pessoas com mobilidade reduzida avaliam a acessibilidade de espaços públicos e denunciam barreiras arquitetônicas.

Projeto da disciplina de Programação Orientada a Objetos — tema *Tecnologia para o Impacto Social*.

**ODS relacionado:** ODS 10 (Redução das Desigualdades — meta 10.2: promover a inclusão social e a acessibilidade para todos).

## Como executar

Requisito: Python 3.9 ou superior (não usa bibliotecas externas).

```bash
python main.py          # menu interativo
python main.py --demo   # demonstração automática de todo o fluxo
