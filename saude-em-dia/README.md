# 💊 App Saúde em Dia (ODS 3)

Protótipo em Python (console) de um sistema de lembretes de medicação, vacinação e consultas voltado a idosos e cuidadores, com alertas automáticos para familiares em caso de não confirmação.

Projeto da disciplina de Programação Orientada a Objetos — tema *Tecnologia para o Impacto Social*.

**ODS relacionado:** ODS 3 (Saúde e Bem-Estar — metas 3.4 e 3.8: prevenção de agravamentos por doenças crônicas e adesão ao cuidado contínuo).

## Como executar

Requisito: Python 3.9 ou superior (não usa bibliotecas externas).

```bash
python main.py          # menu interativo
python main.py --demo   # demonstração automática de todo o fluxo
