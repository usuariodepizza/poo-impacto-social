# 🛡️ Rede Mulher Segura (ODS 5)

Protótipo em Python (console) de uma plataforma de denúncia anônima, mapeamento de pontos de apoio e conexão de mulheres em situação de violência com psicólogas e advogadas voluntárias.

Projeto da disciplina de Programação Orientada a Objetos — tema *Tecnologia para o Impacto Social*.

**ODS relacionado:** ODS 5 (Igualdade de Gênero — metas 5.1 e 5.2: eliminar todas as formas de discriminação e violência contra todas as mulheres e meninas).

## Como executar

Requisito: Python 3.9 ou superior (não usa bibliotecas externas).

```bash
python main.py          # menu interativo
python main.py --demo   # demonstração automática de todo o fluxo
