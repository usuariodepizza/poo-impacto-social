# 💻 Tecnologia para o Impacto Social — POO

Repositório com três soluções de software desenvolvidas aplicando os pilares da Programação Orientada a Objetos (Abstração, Encapsulamento, Herança, Polimorfismo, Composição e Agregação), alinhadas aos Objetivos de Desenvolvimento Sustentável (ODS) da ONU.

## Soluções

1. **[mulher-segura](./mulher-segura)** – **Rede Mulher Segura (ODS 5: Igualdade de Gênero):** Plataforma de denúncia anônima, mapeamento de pontos de apoio e conexão com psicólogas e advogadas voluntárias.
2. **[rota-acessivel](./rota-acessivel)** – **App Rota Acessível (ODS 10: Redução das Desigualdades):** Mapa colaborativo para avaliação de acessibilidade e denúncia de barreiras arquitetônicas em espaços públicos.
3. **[saude-em-dia](./saude-em-dia)** – **App Saúde em Dia (ODS 3: Saúde e Bem-Estar):** Sistema de lembretes de medicação, vacinas e consultas para idosos e cuidadores, com alertas automáticos a familiares.

## Como executar cada projeto

Entre na pasta da solução desejada e execute:

```bash
python main.py --demo   # demonstração automática
python main.py          # menu interativo
```
